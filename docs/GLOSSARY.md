# Glossary

One name per thing, used in the UI, the code, and the stories.

- **Task**: one thing to do. Has a title, optional notes, optional due date, a project, and a done state.
- **Project**: a named group of tasks with a color. Shown in the sidebar under the smart lists.
- **Inbox**: tasks with no project. **Today**: due today or overdue. **Upcoming**: due after today. **Someday**: flagged someday, no date. **Logbook** is not a page in version one; done tasks fade from their list.
- **Session**: a timed stretch of work on one task. Planned minutes, started, ended. "Start session", "Pause", "Resume", "Stop". Overflow: time past the plan, shown as "+2:30".
- **Recording**: a screen capture tied to a session. "Record" starts it, "Stop recording" ends it. Lives in Recordings.
- **Chapter**: a task completed while recording, with its offset into the recording. Exported as a "chapter list".
- **Menu bar timer**: the menu bar extra that shows the countdown.
- **Start/stop hotkey**: Control-Option-Command-S by default.
